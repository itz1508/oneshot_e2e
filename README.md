# OneShot
Agentic build-and-prove system.

## Requirements
Node >= 24, npm >= 11, Python >= 3.11

## Install
git clone https://github.com/itz1508/oneshot_e2e.git && cd oneshot_e2e
npm ci && npm --prefix app/web ci && npm run build

## Run
npm start          # http://localhost:8787
npm run judge      # judge/evaluation
