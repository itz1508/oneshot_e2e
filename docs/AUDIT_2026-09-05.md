# Repository audit: 2026-09-05

Starting revision: `978b5006c5258abc28f32672de36d5ea300aeb4d` on
`migration/oneshot-executable-v1`. The working tree already contained the
reasoner migration and pipeline recovery changes. Those changes were preserved

were retained outside the repository in the session temporary directory.

## Confirmed findings and fixes

- npm reported 14 backend and three frontend vulnerability entries. Removed
  unused `moment` and `jwt-decode` dependencies and added patched transitive
  dependency overrides for OpenTelemetry core, adm-zip, gaxios's uuid, and qs.
  Both audits now report zero known vulnerabilities; `npm ls --all` succeeds.
  ADK remains at 2.0.0; the audit tool's proposed downgrade was not applied.
- Python wheel creation failed because Hatch could not identify the `app`
  package. Explicit package selection and schema inclusion now produce a wheel
  whose contract loader works outside the checkout. The editable Docker install
  receives the canonical schemas through the repository build context.
- Python validated requests after defaults and coercion, accepting wire payloads
  rejected by the TypeScript JSON Schema validator. Validation now checks the
  original input first. Added rejection cases for missing collections, missing
  confidence, string confidence, and unexpected fields.
- Schema export overwrote authoritative contracts with Pydantic-generated
  alternatives. Exports now go to comparison artifacts; documentation preserves
  the shared JSON Schema as the contract authority.
- Consolidated duplicated server/worker reasoner initialization. Removed URL
  logging from this initialization. Invalid non-ASCII bearer tokens no longer
  raise a comparison TypeError. Removed the default credential from the image.
  Development Compose ports bind only to loopback because this stack uses
  sample mode, a public development token, and unauthenticated Redis.
- The canary adapter read nonexistent `plan.tasks` and top-level evidence,
  discarded canonical steps, and fabricated successful evaluation evidence.
  Typed mappings now preserve `plan.steps` and `researcher.evidence`; absent
  evidence remains absent. Two focused adapter tests pass.
- The worker health probe opened a Redis connection for legacy queue checks,
  hanging the baseline suite. Legacy health retains its existing queue semantics;
  pipeline probes use a ready producer connection and bounded SCAN iterations
  instead of KEYS. Worker close now forwards its force argument.
- CI selected Node 22 despite the package engine requirement, omitted frontend
  dependency installation, and invoked a nonexistent compiled recovery script.
  CI now reads Node requirements from package.json and invokes the source script.
  The development image uses Node 24 and copies vendored npm tarballs before ci.
- Recovery assertions now allow an absent worker while checking API queue/Redis
  readiness, require the deliberate crash exit code, disable inherited recovery
  faults, and bound HTTP requests.
