# SKILL.md — OneShot Canonical Contract Builder

## Skill

```text
oneshot-canonical-contracts
```

## Purpose

Create, validate, audit, and maintain the machine-readable contracts that support the OneShot canonical workflow.

The Skill converts established workflow responsibilities into:

```text
JSON Schema contracts
strict runtime models
contract registry entries
artifact ownership mappings
workflow graph definitions
canonicalization implementation
hash verification
schema/runtime parity tests
E2E fixtures
```

The Skill preserves the established workflow:

```text
Prompt_id
→ Researcher
→ Researcher(id)
→ Planner
→ audit_id
→ Refactor
→ plan_id
→ Gap Analysis
→ gap_0 + plan_id
→ Evaluation
→ plan_id
→ Triple Validation
   ├── Schema
   ├── Fixture
   └── Goal
→ CONFIRMED
→ CREATE HASH
→ HASH
→ DONE
```

# Contract Authority

```text
artifact JSON
↓
canonical JSON Schema
↓
strict Python runtime model
↓
workflow operation
```

```python
ConfigDict(extra="forbid")
```

# Operating Procedure

## Step 1 — Load Canonical Workflow

Read the current canonical workflow definition.

Extract:

```text
processors
artifact IDs
producer ownership
consumer relationships
validation relationships
completion sequence
```

Create an in-memory artifact map.

Example:

```text
plan_id
producer: Researcher
consumers:
  Planner
  Refactor
  GapAnalysis
  Evaluation
  TripleValidation
```

---

# Step 2 — Build Artifact Inventory

Produce:

```text
artifact
├── artifact identity
├── owner
├── consumers
├── canonical schema
└── runtime representation
```

Required core artifacts:

```text
Prompt_id
Researcher(id)
plan_id
schema_id
fixture_id
goal_id
validation_id
audit_id
gap_0
evaluation
triple_validation
confirmed_package
HASH
hash_proof
```

---

# Step 3 — Author JSON Schema

For every canonical artifact:

1. Create the schema.
2. Assign canonical contract identity.
3. Define every field.
4. Define required fields.
5. Define nested structures.
6. Define accepted result vocabulary.
7. Close structured objects with `additionalProperties: false`.
8. Validate the schema itself with a Draft 2020-12 validator.

Contract identity format:

```text
urn:oneshot:schema:<name>:<version>
```

---

# Step 4 — Build Runtime Models

Create strict Pydantic models matching the canonical schema.

Base:

```python
from pydantic import BaseModel, ConfigDict


class StrictModel(BaseModel):
    model_config = ConfigDict(
        extra="forbid"
    )
```

Map each canonical artifact to a runtime model.

---

# Step 5 — Prove Schema/Runtime Parity

For each canonical fixture:

```text
Schema accepts
↔
Pydantic accepts
```

and:

```text
Schema rejects
↔
Pydantic rejects
```

Test:

```text
required fields
wrong field types
nested structures
unknown fields
valid enums
invalid enums
arrays
identifiers
result values
```

Produce parity evidence for every contract.

# Step 7 — Build Workflow Graph

# Step 13 — Execute Triple Validation

Resolve `validation_id`.

Run:

```text
Schema Validation
Fixture Validation
Goal Validation
```

Each returns:

```text
VALID
or
NOT_VALID
```

Aggregate:

```text
all_valid =
schema == VALID
AND
fixture == VALID
AND
goal == VALID
```

When `all_valid == true`, create the confirmed package.

---

# Step 14 — Build Confirmed Package

Assemble:

```text
confirmed_package.core
├── researcher

├── schema_artifact
├── fixture
├── goal
├── validation
├── audit
├── gap_analysis
├── evaluation
└── triple_validation
```

Validate every nested artifact.

Validate the full package.

Set:

```text
confirmed = true
```

---

# Step 15 — Canonicalize

Canonicalization identity:

```text
oneshot-jcs-rfc8785-v1
```

Input:

```text
confirmed_package.core
```

Apply RFC 8785 JCS.

Output:

```text
canonical_bytes
```

---

# Step 16 — Create Hash

Compute:

```text
HASH =
SHA256(canonical_bytes)
```

Store lowercase hexadecimal digest.

Record:

```text
canonicalization_id
algorithm
created_hash
```

---

# Step 17 — Verify Hash

Use the exact same confirmed immutable core.

Independently execute:

```text
confirmed_package.core
↓
RFC 8785 JCS
↓
canonical bytes
↓
SHA-256
↓
recomputed_hash
```

Compare:

```text
created_hash == recomputed_hash
```

Record both values in `hash_proof`.
